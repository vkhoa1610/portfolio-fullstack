## Session 2: MinIO S3-Compatible Storage — Receipt Upload thực sự

### Mục tiêu
Thay thế mock upload trong scan-view bằng upload thật lên MinIO (S3-compatible). Browser upload trực tiếp bằng presigned PUT URL (bypass backend). Docker-compose tự bundle MinIO → recruiter chỉ cần `docker-compose up`.

### Upload Flow mới
```
1. User chọn file → frontend tạo blob preview URL ngay lập tức
2. Frontend GET /expenses/upload-url?filename=xxx → BFF → Backend → MinIO presigned PUT URL (15 phút)
3. Frontend PUT file trực tiếp lên MinIO (bypass backend hoàn toàn)
4. Frontend POST /expenses/scan { fileUrl } → BFF → Backend mock OCR
5. Frontend tạo expense với receiptFileUrl = fileUrl (URL công khai tới MinIO)
```

---

### Step 1: Infrastructure (docker-compose.yml)

- Thêm service `minio` (image: minio/minio:latest, port 9000/9001, volume `minio_data`, healthcheck)
- Thêm service `minio-init` (image: minio/mc:latest) với block scalar entrypoint:
  ```
  mc alias set local http://minio:9000 minioadmin minioadmin
  mc mb local/receipts --ignore-existing
  mc anonymous set download local/receipts
  printf '{"CORSRules":[...]}' > /tmp/cors.json
  mc cors set local/receipts --config-file /tmp/cors.json
  ```
- Thêm env vars cho `backend`: `STORAGE_ENDPOINT`, `STORAGE_PUBLIC_ENDPOINT`, `STORAGE_ACCESS_KEY`, `STORAGE_SECRET_KEY`, `STORAGE_BUCKET`
- Thêm `depends_on: minio: condition: service_healthy` cho backend
- Thêm `volumes: minio_data:`

### Bugs đã gặp và fix

| Bug | Root Cause | Fix |
| --- | ---------- | --- |
| Upload không hoạt động, không có error | S3Presigner dùng internal endpoint `minio:9000` → browser không reach được | S3Presigner dùng `publicEndpoint = http://localhost:9000` |
| Browser CORS block PUT request | MinIO chưa config CORS cho bucket | `minio-init` chạy `mc cors set` với JSON config |
| Error im lặng, không có feedback | `uploadError` state chưa có, catch block không set state | Thêm `uploadError` state và error banner display |
| MinIO XML error: `invalid character entity &` | Java SDK gọi `createBucket` + `putBucketCors` gây lỗi XML parser của MinIO | Xóa hoàn toàn `initBucketAndCors` khỏi Java; delegate cho `minio-init` mc script |
| `fileUrl` bị double path: `receipts/receipts/UUID.png` | `key = "receipts/" + UUID` + `fileUrl = endpoint + "/" + bucket + "/" + key` | Đổi key = `UUID + ext` (bỏ prefix `receipts/`) |
| Presigned URL dạng virtual-hosted: `receipts.localhost:9000/UUID.png` → 400 | S3Presigner thiếu `pathStyleAccessEnabled(true)` → SDK dùng subdomain style | Thêm `.serviceConfiguration(S3Configuration.builder().pathStyleAccessEnabled(true).build())` |
