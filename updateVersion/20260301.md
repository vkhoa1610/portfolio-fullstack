## Session 3: BFF Refactor — Domain-based Naming


- 2 `ExportCard` components (DATEV + XRechnung) với metadata display

### Step 6: ESLint / TypeScript Fixes

| Lỗi | Root Cause | Fix |
| --- | ---------- | --- |
| `STATUS_BADGE` unused (`check-view.tsx`) | Constant không dùng | Xóa constant + import `ExpenseStatus` |
| `jsx-a11y/label-has-associated-control` (`export-view.tsx`) | `<label>` không liên kết input | Đổi `<label>` → `<p>` |
| Unused ternary expression (`payment-view.tsx`) | ESLint no-unused-expressions | Đổi sang `if/else` block |
| `PAID` missing in `Record<ExpenseStatus, ...>` | TypeScript exhaustive check | Thêm `PAID` vào `STATUS_CONFIG`, `STATUS_STYLE`, `STATUS_LABEL` |
| Duplicate key `expense` trong `en.json` | Append block mới thay vì merge | Gộp `status_paid` vào block hiện có, xóa duplicate |
| Arrow param `(t) =>` conflict với `t` translation | Naming collision | Đổi `(t) => byType[t]` → `(expType) => byType[expType]` |
