## Session 1: Fix Login Flow (Docker)

### Vấn đề
- `localhost:3000/auth/login` không hoạt động khi chạy toàn hệ thống Docker
- BFF không kết nối được Spring Boot backend

### Root Causes & Fixes

| Bug | Root Cause | Fix |
| --- | ---------- | --- |
| Login request 404 tại `localhost:3000/api/*` | Next.js không có route `/api/*`, browser không đến được BFF | Thêm `rewrites()` trong `next.config.ts` proxy `/api/*` → BFF |
| Rewrite vẫn dùng `localhost:4000` trong Docker | Next.js rewrites compile lúc `next build` (không phải runtime) → fallback baked in | Thêm `ARG BFF_INTERNAL_URL=http://nextjs-bff:4000` vào Dockerfile builder stage **trước** `RUN npm run build` |
| BFF trả lỗi khi gọi backend | `JAVA_API_URL` không set → default `localhost:8080` không resolve trong Docker | Thêm `JAVA_API_URL=http://spring-backend:8080` vào BFF environment trong `docker-compose.yml` |

### Files changed
- `frontend/next.config.ts` — thêm `rewrites()`
- `frontend/Dockerfile` — thêm `ARG BFF_INTERNAL_URL` + `ENV` trước `npm run build`
- `docker-compose.yml` — thêm build args + `JAVA_API_URL` cho BFF

### Flow hoàn chỉnh sau implement

```
Login (onboardingStatus: PENDING)
  → BFF trả redirectTo: '/onboarding'
  → Frontend navigate /onboarding → middleware.ts check cookie → ok
  → /onboarding/page.tsx redirect → /onboarding/compliance

/onboarding/compliance
  ├── User check 2 checkbox
  └── Click Continue → POST /api/onboarding/consent { policyIds: [1, 2] }
        → BFF product-008 → Backend POST /api/v1/onboarding/consent
        → INSERT user_consents (2 records)
        → navigate /onboarding/profile

/onboarding/profile
  ├── Hiển thị role thật (từ session)
  ├── User chọn language
  └── Click Submit → POST /api/onboarding/profile { languageCode }
        → BFF product-009 → Backend POST /api/v1/onboarding/profile
        → UPSERT user_profiles (tạo record → onboardingStatus → DONE)
        → navigate /dashboard

Login lần sau (onboardingStatus: DONE)
  → BFF trả redirectTo: '/dashboard' (bỏ qua onboarding)
```

## Session 4: Bug Fixes — TypeScript Build Error + DB Schema

### Fix 1: TypeScript build error — `ProtectedRoute` role type mismatch

**Lỗi:**
```
Type error: This comparison appears to be unintentional because the types
'"EMPLOYEE" | "MANAGER" | "FINANCE" | undefined' and '"USER" | "ADMIN"' have no overlap.
```

**Root cause:** `ProtectedRouteProps.requiredRole` được định nghĩa là `"USER" | "ADMIN"` trong khi `UISession.user.role` là `"EMPLOYEE" | "MANAGER" | "FINANCE"` — TypeScript từ chối so sánh 2 type không có overlap.

**Fix:** Đổi `requiredRole` type trong `ProtectedRoute` khớp với `UISession`.

**File changed:**
- `frontend/components/auth/ProtectedRoute.tsx` — đổi `requiredRole?: "USER" | "ADMIN"` → `"EMPLOYEE" | "MANAGER" | "FINANCE"`
