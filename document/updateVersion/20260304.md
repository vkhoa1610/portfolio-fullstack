## Fix: Admin Login Redirect

**Vấn đề**: Admin login bị redirect về `/onboarding` (thiếu user_profiles) hoặc `/dashboard` (getRedirectUrl không check isAdmin).

**Fix**:
- `getRedirectUrl(profile, isAdmin)`: `if (isAdmin) return '/admin'` — ưu tiên trước onboardingStatus
- `LoginSuccessResponse.redirectTo` type: thêm `| '/admin'`
- com-001/002/003: `getRedirectUrl(userProfile, isAdmin)` — truyền isAdmin
- DB seed: thêm `user_profiles` cho admin user

## Kiểm tra

1. **DB**: `system_admins` + `user_profiles` admin seed tồn tại
2. **Java**: `GET /api/v1/users/me/is-admin` với admin token → `{ isAdmin: true }`
3. **Java**: `GET /api/v1/users/me/is-admin` với manager token → `{ isAdmin: false }`
4. **Java**: `GET /api/v1/admin/users/:sub/permissions/status` → 4 permissions với state đúng
5. **Java**: Revoke permission → `is_active=0` trong DB (record còn, không bị xóa)
6. **Java**: Re-grant → `is_active=1` lại (UPSERT)
7. **BFF**: Login admin → `session.isAdmin: true`, `redirectTo: '/admin'`
8. **Frontend**: Login non-admin → navigate `/admin` → redirect `/not-found`
9. **Frontend**: Login admin → `/admin/users/:sub` → 2 bảng 3-state hiển thị đúng
10. **Frontend**: Toggle permission → bảng refresh tự động (RTK invalidatesTags)
11. **CSV**: Download template → fill → upload → preview → Confirm → ImportResult hiển thị
