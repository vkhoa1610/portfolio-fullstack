### Finance Payment Logic

```
Finance user gọi PUT /finance/expenses/{id}/pay
    → markPaid(id, paidAt) → status = PAID, updated_at = now

Finance user gọi PUT /finance/expenses/batch-pay { ids: [...] }
    → markBatchPaid(ids, paidAt) → batch UPDATE với <foreach>

@Scheduled(cron = "0 0 8 * * ?")   — chạy mỗi ngày 8:00 SA
    → nếu hôm nay là ngày 15 hoặc ngày cuối tháng
        → findAllApproved() → markBatchPaid(allApprovedIds)
```

### package.json scripts

| Script | Nội dung |
|--------|----------|
| `docker:up:ai` | `docker-compose down --remove-orphans && docker-compose --profile ai up --build` |

| `docker:ai:off` | `docker-compose --profile ai stop ollama ollama-init` |
