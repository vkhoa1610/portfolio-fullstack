# FIN-002 — POST /fin-002 (Planned)

> ❌ **Chưa implement** — Frontend mock local state khi endpoint trả lỗi.

## Mô tả

Đánh dấu một batch expenses là PAID sau khi accountant hoàn tất SEPA bank transfer.

## Process Flow (target)

```
Frontend gửi POST { ids: number[] }
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: POST /api/v1/finance/expenses/mark-paid
  → Backend cập nhật status APPROVED → PAID cho từng id
  → Trả { success: true, paidIds: number[] }
```

---

## BFF Endpoint (planned)

- **Method**: POST
- **Path**: `/api/fin-002`
- **Auth**: HttpOnly cookies (idToken required) — FINANCE role

---

## Input (Request Body)

| Field | Required | Type       | Ghi chú                           |
|-------|----------|------------|-----------------------------------|
| ids   | ✅       | number[]   | Danh sách expense IDs cần mark paid |

---

## Output (planned)

| Field    | Type     | Ghi chú                        |
|----------|----------|--------------------------------|
| success  | boolean  |                                |
| paidIds  | number[] | IDs đã được mark thành công    |

---

## Frontend Behavior hiện tại (mock)

// payment-view.tsx
try {

  // Backend chưa có → 404/error bị catch

  setPaidIds((prev) => new Set([...prev, ...ids]));

## Backend cần implement

```
POST /api/v1/finance/expenses/mark-paid
Body: { ids: [1, 2, 3] }
Action: UPDATE expenses SET status = 'PAID' WHERE id IN (ids) AND status = 'APPROVED'
Response: { success: true, paidIds: [...] }
```

DB: Cần thêm `'PAID'` vào ENUM `expense_status` trong `TableMaster.sql`.
