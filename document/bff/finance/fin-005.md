# fin-005 — GET List Finance Reports

> Cập nhật: 2026-03-26 (Session 8 — Flow 11)

## Endpoint

```
GET /fin-005/reports
Auth: idToken required
```

## Backend Target

```
GET /api/v1/finance/reports
Host: JAVA_API_URL
Authorization: Bearer {idToken}
```

## Response

`FinanceReport[]` — tất cả finance reports, order by `created_at DESC`.

**Frontend transform** (trong RTK Query `transformResponse`): parse JSON strings về objects:
- `lineItems` — JSON string → `LineItem[]`
- `attachments` — JSON string → `ReportAttachment[]`
- `approvalRoute` — JSON string → `ApprovalLevel[]`
- `notifyCc` — JSON string → `{ name: string }[]`
