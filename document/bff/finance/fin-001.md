```
Frontend (Finance role) gửi GET
  → BFF validate idToken từ cookie
  → [Temporary] Forward đến Java Backend: GET /api/v1/manager/expenses
```

## Output (Response to Frontend)

Trả về mảng `Expense[]` — tất cả expenses (tất cả users, tất cả status).

| Field           | Required | Type   | Ghi chú                                                    |
|-----------------|----------|--------|------------------------------------------------------------|
| id              | ✅       | number |                                                            |
| userSub         | ✅       | string | Cognito sub của employee                                   |
| type            | ✅       | string | `RECEIPT` \| `PER_DIEM` \| `MILEAGE`                      |
| status          | ✅       | string | `DRAFT` \| `PENDING_REVIEW` \| `APPROVED` \| `REJECTED` \| `PAID` |
| amount          | ❌       | number |                                                            |
| currency        | ✅       | string |                                                            |
| title           | ❌       | string |                                                            |
| vendorName      | ❌       | string | RECEIPT type                                               |
| vatAmount       | ❌       | number | RECEIPT type                                               |
| fromDate        | ❌       | string | PER_DIEM type                                              |
| toDate          | ❌       | string | PER_DIEM type                                              |
| distanceKm      | ❌       | number | MILEAGE type                                               |
| aiFlags         | ❌       | string | AI warning flags từ OCR                                    |
| submittedAt     | ❌       | string | ISO datetime                                               |
| createdAt       | ❌       | string | ISO datetime                                               |
