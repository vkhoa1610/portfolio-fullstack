# MGR-004 — GET /manager/expenses/:id

## Process Flow

```
Frontend (Manager) gửi GET /api/mgr-004/:id
  → Re-use hoàn toàn controller của emp-005
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: GET /api/v1/expenses/:id
  → Trả Expense object (full detail)
```

> **Lưu ý**: mgr-004 là alias của emp-005. Handler giống hệt nhau.
> Manager dùng endpoint này để xem chi tiết expense trước khi approve/reject.

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/mgr-004/:id`
- **Auth**: HttpOnly cookies (idToken required) — MANAGER role

---

## Input (Path Params)

| Field | Required | Type   | Ghi chú    |
|-------|----------|--------|------------|
| id    | ✅       | number | ID expense |
