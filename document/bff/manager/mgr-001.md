# MGR-001 — GET /manager/expenses

## Process Flow

```
Frontend (Manager) gửi GET
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: GET /api/v1/manager/expenses
  → Backend trả danh sách expenses có status = PENDING_REVIEW
  → Trả Expense[]
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/mgr-001`
- **Auth**: HttpOnly cookies (idToken required) — chỉ MANAGER role

---

## Input

Không có request body / query params.

---

## Output (Response to Frontend)

Trả về mảng `Expense[]` — chỉ những expense có status `PENDING_REVIEW`.

| Field           | Required | Type   | Ghi chú                                         |
|-----------------|----------|--------|-------------------------------------------------|
| id              | ✅       | number |                                                 |
| userSub         | ✅       | string | Cognito sub của employee                        |
| type            | ✅       | string | `RECEIPT` \| `PER_DIEM` \| `MILEAGE`          |
| status          | ✅       | string | `PENDING_REVIEW`                                |
| amount          | ❌       | number |                                                 |
| currency        | ✅       | string |                                                 |
| title           | ❌       | string |                                                 |
| submittedAt     | ❌       | string | ISO datetime                                    |
| createdAt       | ❌       | string | ISO datetime                                    |

---

|--------|-----------------------------|----------------|
