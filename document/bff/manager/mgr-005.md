# MGR-005 — GET /mgr-005/reports/latest

> Manager xem (read-only) report AI mới nhất. Không có quyền generate — chỉ xem report đã được admin tạo.

## Endpoint

- **Method**: GET
- **BFF Path**: `/mgr-005/reports/latest`
- **Backend**: GET `/api/v1/manager/reports/latest`
- **Auth**: Bearer idToken (HttpOnly cookie) — MANAGER role

> **Lưu ý**: Backend endpoint này đặt ở `/api/v1/manager/` (không phải `/api/v1/admin/`) để bỏ qua `requireAdmin` check. Role gate được thực hiện ở BFF layer qua JWT.

## Output (có report)

```json
{
  "exists": true,
  "id": 42,
  "period": "2026-03",
  "status": "DONE",
  "markdown": "## Executive Summary\n...",
  "reportData": "{...}",
  "generatedAt": "2026-03-22T14:10:43"
}
```

## Output (chưa có report)

```json
{ "exists": false }
```

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 401 | Không có idToken |
| 403 | User không phải MANAGER role |
