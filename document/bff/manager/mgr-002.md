# MGR-002 — PUT /manager/expenses/:id/approve

## Process Flow

```
Frontend (Manager) gửi PUT /api/mgr-002/:id
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: PUT /api/v1/manager/expenses/:id/approve (body rỗng)
  → Backend đổi status: PENDING_REVIEW → APPROVED
    → Ghi reviewedAt, reviewedBy (cognito sub của manager)
  → Trả { processStatus, message }
```

---

## BFF Endpoint

- **Method**: PUT
- **Path**: `/api/mgr-002/:id`
- **Auth**: HttpOnly cookies (idToken required) — chỉ MANAGER role

---

## Input (Path Params)

| Field | Required | Type   | Ghi chú                 |
|-------|----------|--------|-------------------------|
| id    | ✅       | number | ID expense cần approve  |

Không có request body.

---

## Output (Response to Frontend)

| Field         | Required | Type     | Ghi chú      |
|---------------|----------|----------|--------------|
| processStatus | ✅       | number   | 1 = SUCCESS  |
| message       | ✅       | string[] |              |

---

## Backend API Gọi

| Method | URL                                      | Auth           |
|--------|------------------------------------------|----------------|
| PUT    | `/api/v1/manager/expenses/:id/approve`   | Bearer idToken |

Request body rỗng `{}`.
