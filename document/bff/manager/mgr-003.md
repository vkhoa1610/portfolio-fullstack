# MGR-003 — PUT /manager/expenses/:id/reject

## Process Flow

```
Frontend (Manager) gửi PUT /api/mgr-003/:id { rejectionReason }
  → BFF validate idToken từ cookie
  → BFF validate: rejectionReason required
  → Forward đến Java Backend: PUT /api/v1/manager/expenses/:id/reject { rejectionReason }
  → Backend đổi status: PENDING_REVIEW → REJECTED
    → Ghi rejectionReason, reviewedAt, reviewedBy
  → Trả { processStatus, message }
```

---

## BFF Endpoint

- **Method**: PUT
- **Path**: `/api/mgr-003/:id`
- **Auth**: HttpOnly cookies (idToken required) — chỉ MANAGER role

---
