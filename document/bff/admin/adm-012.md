# ADM-012 — GET /adm-012/reports/status/:jobId

> Poll trạng thái của một report generation job.

## Endpoint

- **Method**: GET
- **BFF Path**: `/adm-012/reports/status/:jobId`
- **Backend**: GET `/api/v1/admin/reports/status/{jobId}`
- **Auth**: Bearer idToken (HttpOnly cookie)

## Input

| Param | Vị trí | Ghi chú |
|-------|--------|---------|
| jobId | path | ID của job từ adm-011 |

## Output

```json
{
  "id": 42,
  "period": "2026-03",
  "status": "DONE",
  "markdown": "## Executive Summary\n...",
  "reportData": "{...}",
  "errorMsg": null,
  "generatedAt": "2026-03-19T14:30:00"
}
```

`status` có thể là `PENDING`, `DONE`, hoặc `FAILED`.

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 401 | Không có idToken |
| 403 | User không phải system_admin |
| 404 | jobId không tồn tại |
