# ADM-008 — POST /adm-008/import/users

> Bulk import users từ file CSV. BFF forward multipart đến Java backend.

## Process Flow

```
Frontend upload file CSV → POST /api/adm-008/import/users (multipart/form-data)
  → BFF: multer (memoryStorage) parse file vào req.file.buffer
  → BFF rebuild FormData với form-data npm package
  → Forward: POST /api/v1/admin/import/users (multipart, Bearer idToken)
  → Java CsvImportService xử lý từng row
  → Trả ImportResult { successCount, failCount, errors }
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/adm-008/import/users`
- **Content-Type**: `multipart/form-data`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-008/controller.ts`

## Kỹ thuật BFF (multipart forward)

```typescript
// multer inline (không mount middleware global)
const upload = multer({ storage: multer.memoryStorage() });
await new Promise<void>((resolve, reject) => {
  upload.single('file')(req, res, (err) => { err ? reject(err) : resolve(); });
});

// Rebuild với form-data
const formData = new FormData();
formData.append('file', req.file.buffer, {
  filename: req.file.originalname || 'users.csv',
  contentType: req.file.mimetype || 'text/csv',
});

const response = await apiClient.post('/api/v1/admin/import/users', formData, {
  baseURL: JAVA_API_URL,
  headers: { Authorization: `Bearer ${idToken}`, ...formData.getHeaders() },
});
```
