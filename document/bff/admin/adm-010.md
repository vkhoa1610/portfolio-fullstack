# ADM-010 — GET /adm-010/template/:type

> Download file CSV template để admin fill offline trước khi import.

## Process Flow

```
Frontend gọi GET /api/adm-010/template/:type
  → BFF lấy idToken từ cookie
  → Forward: GET /api/v1/admin/import/template/:type (Bearer idToken, responseType: arraybuffer)
  → Java trả file CSV với header Content-Disposition
  → BFF forward buffer + Content-Type + Content-Disposition về frontend
  → Browser download file tự động
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/adm-010/template/:type`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-010/controller.ts`

---

## Input (Path Params)

| Field | Required | Type | Ghi chú |
|-------|----------|------|---------|
| type | ✅ | string | `users` hoặc `permissions` |

---

## Output

Binary CSV file download:

| type | Filename | Content |
|------|----------|---------|
| `users` | `users_template.csv` | `Email,Role,Budget\n` |
| `permissions` | `permissions_template.csv` | `User Email,Permission Code,Action\n` |

---

## Backend API Gọi

| Method | URL | Auth |
|--------|-----|------|
| GET | `/api/v1/admin/import/template/:type` | Bearer idToken |

---

## Kỹ thuật BFF (stream download)

```typescript
const response = await apiClient.get(`/api/v1/admin/import/template/${type}`, {
  baseURL: JAVA_API_URL,
  headers: { Authorization: `Bearer ${idToken}` },
  responseType: 'arraybuffer',
});
res.set('Content-Type', 'text/csv');
res.set(
  'Content-Disposition',
  response.headers['content-disposition'] || `attachment; filename="${type}_template.csv"`,
);
return res.send(Buffer.from(response.data));
```
