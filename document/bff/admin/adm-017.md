# ADM-017 — AI Playground Chat

> Proxy cho admin test trực tiếp input/output của AI model (Ollama) với custom system prompt + user prompt.

## Endpoint

- **Method**: POST
- **BFF Path**: `/adm-017/ai-playground/chat`
- **Backend**: POST `/api/v1/admin/ai-playground/chat`
- **Auth**: Bearer idToken (HttpOnly cookie) — admin only
- **Timeout**: 150,000ms (2.5 phút) — LLM có thể chậm khi khởi động

## Input

```json
{
  "systemPrompt": "You are a financial analyst...",
  "userPrompt": "Analyze the following expense data: ..."
}
```

| Field | Required | Mô tả |
|-------|----------|-------|
| `systemPrompt` | Optional | System instruction cho model |
| `userPrompt` | ✅ | User message — nội dung cần AI trả lời |

## Output (success)

```json
{
  "response": "Based on the expense data...",
  "model": "llama3.2",
  "durationMs": 4523
}
```

## Output (Ollama lỗi / offline)

```json
{
  "error": "Connection refused to Ollama service",
  "model": "llama3.2",
  "durationMs": 12
}
```

## Lỗi BFF

| Status | Trường hợp |
|--------|-----------|
| 400 | userPrompt trống |
| 401 | Không có idToken |
| 403 | User không phải system_admin |
| 500 | Backend không reach được Ollama |
