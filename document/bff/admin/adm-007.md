# ADM-007 — DELETE /adm-007/:sub/functions/:key

> Revoke (soft-delete) một UI function của user.
> Backend set `is_active=0` trong bảng `items`.

## Process Flow

```
Frontend gọi DELETE /api/adm-007/:sub/functions/:key
  → BFF lấy idToken từ cookie
  → Forward: DELETE /api/v1/admin/users/:sub/functions/:key (Bearer idToken)
  → Java: UPDATE items SET is_active=0 WHERE cognito_sub=:sub AND function_id=:id
  → Trả success
```

---

## BFF Endpoint

- **Method**: DELETE
- **Path**: `/api/adm-007/:sub/functions/:key`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-007/controller.ts`
