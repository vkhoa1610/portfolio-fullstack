# ADM-006 — POST /adm-006/:sub/functions

> Grant (hoặc re-activate) một UI function cho user.
> Backend dùng UPSERT — nếu record đã có (INACTIVE) thì set `is_active=1`.

## Process Flow

```
Frontend gọi POST /api/adm-006/:sub/functions { functionKey }
  → BFF lấy idToken từ cookie
  → Forward: POST /api/v1/admin/users/:sub/functions { functionKey } (Bearer idToken)
  → Java UPSERT items: INSERT ON DUPLICATE KEY UPDATE is_active=1
  → Trả success
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/adm-006/:sub/functions`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-006/controller.ts`
