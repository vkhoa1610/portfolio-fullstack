# ADM-013 — GET /adm-013/reports/latest

> Lấy report DONE mới nhất. Dùng khi load trang để hiển thị report cũ nhất nếu có.

## Endpoint

- **Method**: GET
- **BFF Path**: `/adm-013/reports/latest`
- **Backend**: GET `/api/v1/admin/reports/latest`
- **Auth**: Bearer idToken (HttpOnly cookie)

## Output (có report)

```json
{
  "exists": true,
  "id": 42,
  "period": "2026-03",
  "status": "DONE",
  "markdown": "## Executive Summary\n...",
  "reportData": "{...}",
  "generatedAt": "2026-03-19T14:30:00"
}
```

## Output (chưa có report nào)

```json
{ "exists": false }
```

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 401 | Không có idToken |
| 403 | User không phải system_admin |
