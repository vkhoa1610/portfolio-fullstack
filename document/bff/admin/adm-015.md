# ADM-015 — Report Templates (Get One + Update)

> GET và PUT theo ID cho một template cụ thể.

## Endpoints

| Method | BFF Path | Chức năng |
|--------|----------|-----------|
| GET    | `/adm-015/report-templates/:id` | Lấy một template theo ID |
| PUT    | `/adm-015/report-templates/:id` | Cập nhật template |

- **Auth**: Bearer idToken (HttpOnly cookie) — admin only

## GET Output

```json
{
  "id": 1,
  "name": "Default Template",
  "configJson": "{\"title\":\"Expense Report\",\"company\":\"FintechSaaS\",\"primaryColor\":\"#6366F1\",\"sections\":[{\"key\":\"executiveSummary\",\"enabled\":true},{\"key\":\"breakdownByCategory\",\"enabled\":true},{\"key\":\"aiAnalysis\",\"enabled\":true}]}"
}
```

## PUT Input

```json
{
  "name": "Default Template",
  "configJson": "{\"title\":\"Updated Report\",\"company\":\"FintechSaaS\",\"primaryColor\":\"#10B981\",\"sections\":[...]}"
}
```

## PUT Output

Trả về template sau khi update (cùng format GET output).

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 401 | Không có idToken |
| 403 | User không phải system_admin |
| 404 | Template ID không tồn tại |
