# ADM-016 — Generate PDF

> Nhận `templateId` + `reportId`, fetch cả hai từ backend, render HTML qua template engine, rồi dùng Puppeteer (Chromium) để tạo PDF binary trả về client.

## Endpoint

- **Method**: POST
- **BFF Path**: `/adm-016/report-templates/generate-pdf`
- **Auth**: Bearer idToken (HttpOnly cookie) — admin only

## Input

```json
{
  "templateId": 1,
  "reportId": 42
}
```

## Output

- **Content-Type**: `application/pdf`
- **Content-Disposition**: `attachment; filename="expense-report-2026-03.pdf"`
- Binary PDF buffer

## Processing Flow

```
1. Fetch template config → GET /api/v1/admin/report-templates/{templateId}
2. Fetch report data     → GET /api/v1/admin/reports/status/{reportId}
3. Validate report.status === "DONE"
4. buildReportHtml(config, reportData)
     → iterate config.sections (ordered array)
     → renderAiAnalysis() — markdown → HTML (regex, không dùng lib ngoài)
     → inject CSS với primaryColor từ config
5. generatePdf(html) → Puppeteer headless Chromium → Buffer
6. res.send(buffer) với content-type PDF headers
```

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 400 | templateId hoặc reportId không có |
| 400 | Report status !== "DONE" |
| 401 | Không có idToken |
| 403 | User không phải system_admin |
| 500 | Puppeteer/Chromium lỗi |
