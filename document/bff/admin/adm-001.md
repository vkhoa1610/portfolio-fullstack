# ADM-001 — GET /adm-001/users

## Process Flow

```
Frontend (RTK Query useGetAdminUsersQuery) gọi GET /api/adm-001/users
  → BFF lấy idToken từ HttpOnly cookie
  → Forward đến Java: GET /api/v1/admin/users (Bearer idToken)
  → Java kiểm tra system_admins → query tất cả users
  → Trả List<AdminUser>
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/adm-001/users`
- **Auth**: HttpOnly cookies (idToken required)
- **File**: `bff/src/product/admin/adm-001/controller.ts`
