# ADM-009 — POST /adm-009/import/permissions

> Bulk grant/revoke permissions từ file CSV. BFF forward multipart đến Java backend.

## Process Flow

```
Frontend upload file CSV → POST /api/adm-009/import/permissions (multipart/form-data)
  → BFF: multer parse file → rebuild FormData
  → Forward: POST /api/v1/admin/import/permissions (multipart, Bearer idToken)
  → Java CsvImportService: mỗi row → GRANT (UPSERT is_active=1) hoặc REVOKE (is_active=0)
  → Trả ImportResult
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/adm-009/import/permissions`
- **Content-Type**: `multipart/form-data`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-009/controller.ts`

---
