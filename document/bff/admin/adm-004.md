# ADM-004 — DELETE /adm-004/:sub/permissions/:code

> Revoke (soft-delete) một permission của user.
> Backend set `is_active=0` — record vẫn còn trong DB để audit.

## Process Flow

```
Frontend gọi DELETE /api/adm-004/:sub/permissions/:code
  → BFF lấy idToken từ cookie
  → Forward: DELETE /api/v1/admin/users/:sub/permissions/:code (Bearer idToken)
  → Java: UPDATE user_permissions SET is_active=0 WHERE user_sub=:sub AND permission_id=:id
  → Trả success
```

---

## BFF Endpoint

- **Method**: DELETE
- **Path**: `/api/adm-004/:sub/permissions/:code`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-004/controller.ts`

## Ghi chú

- Đây là **soft-delete**: record không bị xóa, chỉ `is_active=0`
- State badge sau khi thành công: `ACTIVE` → `INACTIVE`
- Lần grant lại (adm-003) sẽ giữ nguyên `granted_by` / `created_at` ban đầu
