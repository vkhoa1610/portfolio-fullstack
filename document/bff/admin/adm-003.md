# ADM-003 — POST /adm-003/:sub/permissions

> Grant (hoặc re-activate) một permission cho user.
> Backend dùng UPSERT — nếu record đã có (INACTIVE) thì set `is_active=1`.

## Process Flow

```
Frontend gọi POST /api/adm-003/:sub/permissions { permissionCode }
  → BFF lấy idToken từ cookie
  → Forward: POST /api/v1/admin/users/:sub/permissions { permissionCode } (Bearer idToken)
  → Java UPSERT user_permissions: INSERT ON DUPLICATE KEY UPDATE is_active=1
  → Trả success
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/adm-003/:sub/permissions`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-003/controller.ts`

## Frontend Usage

```typescript
const [grantPermission] = useGrantPermissionMutation();
await grantPermission({ sub, permissionCode: p.permissionCode });
// invalidatesTags: ['UserPermissions'] → tự refresh adm-002
```

## Ghi chú

- NEVER_GRANTED → ACTIVE: tạo record mới `is_active=1`
- INACTIVE → ACTIVE: UPDATE `is_active=1` (UPSERT)
- State badge sau khi thành công: `NEVER_GRANTED` / `INACTIVE` → `ACTIVE`
