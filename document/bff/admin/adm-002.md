# ADM-002 — GET /adm-002/:sub/permissions

> Lấy danh sách toàn bộ permissions với trạng thái 3-state của một user.

## Process Flow

```
Frontend gọi GET /api/adm-002/:sub/permissions
  → BFF lấy idToken từ cookie
  → Forward: GET /api/v1/admin/users/:sub/permissions/status (Bearer idToken)
  → Java trả List<UserPermissionStatusDto> (ACTIVE / INACTIVE / NEVER_GRANTED)
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/adm-002/:sub/permissions`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-002/controller.ts`

---

## Input (Path Params)

| Field | Required | Type |
|-------|----------|------|
| sub | ✅ | string — cognito_sub của user |

---

## Output

```json
[
  { "permissionCode": "EXPENSE_APPROVE", "description": "...", "state": "ACTIVE", "grantedBy": "system", "createdAt": "..." },
  { "permissionCode": "FINANCE_VIEW",    "description": "...", "state": "NEVER_GRANTED", "grantedBy": null, "createdAt": null }
]
```
