# ADM-005 — GET /adm-005/:sub/functions

> Lấy danh sách toàn bộ UI functions với trạng thái 3-state của một user.

## Process Flow

```
Frontend gọi GET /api/adm-005/:sub/functions
  → BFF lấy idToken từ cookie
  → Forward: GET /api/v1/admin/users/:sub/functions/status (Bearer idToken)
  → Java trả List<UserFunctionStatusDto> (ACTIVE / INACTIVE / NEVER_GRANTED)
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/adm-005/:sub/functions`
- **Auth**: HttpOnly cookies
- **File**: `bff/src/product/admin/adm-005/controller.ts`

---

## Input (Path Params)

| Field | Required | Type |
|-------|----------|------|
| sub | ✅ | string — cognito_sub của user |

---

## Output

```json
[
  { "functionId": 1, "functionKey": "EXPENSE_ACCEPT", "module": "MANAGER", "description": "...", "state": "ACTIVE" },
  { "functionId": 2, "functionKey": "EXPENSE_REJECT",  "module": "MANAGER", "description": "...", "state": "NEVER_GRANTED" }
]
```
