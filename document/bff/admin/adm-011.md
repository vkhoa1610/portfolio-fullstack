# ADM-011 — POST /adm-011/reports/generate

> Trigger async AI expense report generation job.

## Endpoint

- **Method**: POST
- **BFF Path**: `/adm-011/reports/generate?period=2026-03`
- **Backend**: POST `/api/v1/admin/reports/generate?period=2026-03`
- **Auth**: Bearer idToken (HttpOnly cookie)

## Input

| Param | Vị trí | Bắt buộc | Ghi chú |
|-------|--------|----------|---------|
| period | query | ✅ | Format "yyyy-MM" |

## Output

```json
{ "jobId": 42, "status": "PENDING" }
```

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 400 | Thiếu period hoặc period sai format |
| 401 | Không có idToken |
| 403 | User không phải system_admin |
