# ADM-014 — Report Templates (List + Create)

> Quản lý report templates dùng để render PDF. ADM-014 xử lý cả GET (list) và POST (create).

## Endpoints

| Method | BFF Path | Chức năng |
|--------|----------|-----------|
| GET    | `/adm-014/report-templates` | Danh sách tất cả templates |
| POST   | `/adm-014/report-templates` | Tạo template mới |

- **Auth**: Bearer idToken (HttpOnly cookie) — admin only

## GET Output

```json
{
  "templates": [
    {
      "id": 1,
      "name": "Default Template",
      "configJson": "{\"title\":\"Expense Report\",\"sections\":[...]}"
    }
  ]
}
```

## POST Input

```json
{
  "name": "Q1 Template",
  "configJson": "{\"title\":\"Q1 Report\",\"company\":\"FintechSaaS\",\"primaryColor\":\"#6366F1\",\"sections\":[{\"key\":\"executiveSummary\",\"enabled\":true}]}"
}
```

## POST Output

```json
{
  "id": 2,
  "name": "Q1 Template",
  "configJson": "..."
}
```

## configJson Schema (TemplateConfig)

```typescript
interface TemplateConfig {
  title: string;
  company: string;
  logoUrl: string;
  primaryColor: string;
  sections: SectionItem[];  // ordered array — thứ tự = thứ tự render PDF
}

type SectionKey = 'executiveSummary' | 'breakdownByCategory' | 'anomalies' | 'recommendations' | 'byEmployee' | 'aiAnalysis';

interface SectionItem {
  key: SectionKey;
  enabled: boolean;
}
```

## Lỗi

| Status | Trường hợp |
|--------|-----------|
| 401 | Không có idToken |
| 403 | User không phải system_admin |
| 400 | configJson không hợp lệ |
