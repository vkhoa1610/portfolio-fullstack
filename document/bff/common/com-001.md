# COM-001 — POST /auth/login

## Process Flow

```
Frontend gửi { email, password }
  → BFF validate input
  → Cognito InitiateAuth (USER_PASSWORD_AUTH)
  ├── Case 1: SUCCESS (no MFA)
  │     → setAuthCookies (HttpOnly: accessToken, idToken, refreshToken)
  │     → fetchUserProfile (GET /api/v1/users/me)
  │     → buildUISession → trả LoginSuccessResponse
  ├── Case 2: SOFTWARE_TOKEN_MFA
  │     → trả MfaRequiredResponse (kèm Cognito session token)
  ├── Case 3: NEW_PASSWORD_REQUIRED
  │     → trả NewPasswordRequiredResponse (kèm Cognito session token)
  └── Case 4: Error → 400/401
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-001`
- **Auth**: Không yêu cầu

---

## Input (Request Body)

| Field    | Required | Type   | Ghi chú              |
|----------|----------|--------|----------------------|
| email    | ✅       | string | Email đăng nhập      |
| password | ✅       | string | Mật khẩu             |

---

## Output (Response to Frontend)

### Case 1 — Login thành công (không có MFA)

| Field         | Required | Type        | Ghi chú                              |
|---------------|----------|-------------|--------------------------------------|
| processStatus | ✅       | number      | 1 = SUCCESS                          |
| message       | ✅       | string[]    | Mô tả kết quả                        |
| authenticated | ✅       | true        | Luôn là `true`                       |
| session       | ✅       | UISession   | Frontend-safe session                |
| redirectTo    | ✅       | string      | `/onboarding` hoặc `/dashboard`      |

**UISession:**

| Field                    | Required | Type                         |
|--------------------------|----------|------------------------------|
| user.email               | ✅       | string                       |
| user.role                | ✅       | `EMPLOYEE` \| `MANAGER` \| `FINANCE` |
| budget                   | ✅       | number                       |
| onboardingStatus         | ✅       | `PENDING` \| `DONE`         |

### Case 2 — MFA Required

| Field          | Required | Type     | Ghi chú                                  |
|----------------|----------|----------|------------------------------------------|
| processStatus  | ✅       | number   | 1 = SUCCESS                              |
| authenticated  | ✅       | false    |                                          |
| mfaRequired    | ✅       | true     |                                          |
| challengeName  | ✅       | string   | `SOFTWARE_TOKEN_MFA`                     |
| session        | ✅       | string   | Cognito session — dùng để gọi com-002    |
| maskedEmail    | ✅       | string   | Ví dụ: `j***@example.com`               |

### Case 3 — New Password Required

| Field               | Required | Type     | Ghi chú                               |
|---------------------|----------|----------|---------------------------------------|
| processStatus       | ✅       | number   |                                       |
| authenticated       | ✅       | false    |                                       |
| newPasswordRequired | ✅       | true     |                                       |
| challengeName       | ✅       | string   | `NEW_PASSWORD_REQUIRED`               |
| session             | ✅       | string   | Cognito session — dùng để gọi com-003 |
| username            | ✅       | string   | Email của user                        |

## Backend API Gọi

| Method | URL                  | Ghi chú                              |
|--------|----------------------|--------------------------------------|
| GET    | `/api/v1/users/me`   | Lấy profile sau khi auth thành công (Case 1 only) |

> Auth với Cognito được thực hiện trực tiếp qua AWS SDK, không qua Java Backend.
