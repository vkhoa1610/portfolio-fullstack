# COM-001 — POST /com-001 — Login

## Process Flow

```
Frontend gửi { email, password }
  → BFF validate input
  → Auth0 Resource Owner Password grant
  ├── Case 1: SUCCESS (no MFA)
  │     → setAuthCookies (HttpOnly: accessToken, refreshToken)
  │     → fetchUserProfile (GET /api/v1/users/me)
  │     → buildUISession → trả LoginSuccessResponse
  ├── Case 2: MFA Required (error: mfa_required)
  │     → trả MfaRequiredResponse (kèm mfa_token làm `session`)
  └── Case 3: Error → 400/401
```

> ⚠️ Auth0 không có `NEW_PASSWORD_REQUIRED` — com-003 trả 410 Gone.

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-001`
- **Auth**: Không yêu cầu

---

## Input (Request Body)

| Field    | Required | Type   | Ghi chú              |
|----------|----------|--------|----------------------|
| email    | ✅       | string | Email đăng nhập      |
| password | ✅       | string | Mật khẩu             |

---

## Output (Response to Frontend)

### Case 1 — Login thành công (không có MFA)

| Field         | Required | Type        | Ghi chú                              |
|---------------|----------|-------------|--------------------------------------|
| processStatus | ✅       | number      | 1 = SUCCESS                          |
| message       | ✅       | string[]    | Mô tả kết quả                        |
| authenticated | ✅       | true        | Luôn là `true`                       |
| session       | ✅       | UISession   | Frontend-safe session                |
| redirectTo    | ✅       | string      | `/onboarding`, `/dashboard`, `/admin`|

**UISession:**

| Field                    | Required | Type                                      |
|--------------------------|----------|-------------------------------------------|
| user.email               | ✅       | string                                    |
| user.role                | ✅       | `EMPLOYEE` \| `MANAGER` \| `FINANCE`     |
| budget                   | ✅       | number                                    |
| onboardingStatus         | ✅       | `PENDING` \| `DONE`                      |
| permissions              | ✅       | string[]                                  |
| functions                | ✅       | number[]                                  |
| isAdmin                  | ✅       | boolean                                   |

### Case 2 — MFA Required

| Field          | Required | Type     | Ghi chú                                         |
|----------------|----------|----------|-------------------------------------------------|
| processStatus  | ✅       | number   | 1 = SUCCESS                                     |
| authenticated  | ✅       | false    |                                                 |
| mfaRequired    | ✅       | true     |                                                 |
| challengeName  | ✅       | string   | `MFA_REQUIRED`                                  |
| session        | ✅       | string   | Auth0 `mfa_token` — opaque, dùng để gọi com-002|
| maskedEmail    | ✅       | string   | Ví dụ: `j***@example.com`                      |

## Auth Provider

Auth0 Resource Owner Password grant (`password-realm`).
Role claim: `https://portfolio.app/role` (namespaced custom claim, set bởi Auth0 Action).

| Method | URL                  | Ghi chú                              |

| GET    | `/api/v1/users/me`   | Lấy profile sau khi auth thành công (Case 1 only) |
