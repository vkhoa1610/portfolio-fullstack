# COM-007 — POST /onboarding/profile

## Process Flow

```
Frontend gửi { languageCode }
  → BFF validate: languageCode required
  → BFF đọc idToken từ HttpOnly cookie (bắt buộc)
  → Forward đến Java Backend: POST /api/v1/onboarding/profile { languageCode }
  → Backend tạo user_profiles record → set onboardingStatus = DONE
  → Trả success
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-007`
- **Auth**: HttpOnly cookies (idToken required)
