# COM-002 — POST /auth/mfa

## Process Flow

```
Frontend gửi { otp, session, email } (session lấy từ com-001 response)
  → BFF gọi Cognito RespondToAuthChallenge (SOFTWARE_TOKEN_MFA)
  → Cognito trả AuthenticationResult
  → setAuthCookies (HttpOnly: accessToken, idToken, refreshToken)
  → fetchUserProfile (GET /api/v1/users/me)
  → buildUISession → trả LoginSuccessResponse
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-002`
- **Auth**: Không yêu cầu (session Cognito được gửi trong body)

---

## Input (Request Body)

| Field   | Required | Type   | Ghi chú                                        |
|---------|----------|--------|------------------------------------------------|
| otp     | ✅       | string | OTP 6 chữ số từ authenticator app             |
| session | ✅       | string | Cognito session nhận từ com-001 (MFA case)     |
| email   | ✅       | string | Email user (dùng để gọi Cognito)               |

---

## Output (Response to Frontend)

| Field         | Required | Type      | Ghi chú                             |
|---------------|----------|-----------|-------------------------------------|
| processStatus | ✅       | number    | 1 = SUCCESS                         |
| message       | ✅       | string[]  |                                     |
| authenticated | ✅       | true      |                                     |
| session       | ✅       | UISession | Frontend-safe session               |
| redirectTo    | ✅       | string    | `/onboarding` hoặc `/dashboard`     |

---

## Backend API Gọi

| Method | URL                | Ghi chú                                      |
|--------|--------------------|----------------------------------------------|
| GET    | `/api/v1/users/me` | Lấy profile sau khi MFA verify thành công   |
