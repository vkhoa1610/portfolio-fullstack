# COM-002 — POST /com-002 — MFA Verification

## Process Flow

```
Frontend gửi { otp, session, email }
  (session = Auth0 mfa_token từ com-001 MFA response)
  → BFF gọi Auth0: grant_type=mfa-otp với mfa_token + otp
  → Auth0 trả access_token + refresh_token
  → setAuthCookies (HttpOnly: accessToken, refreshToken)
  → fetchUserProfile (GET /api/v1/users/me)
  → buildUISession → trả LoginSuccessResponse
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-002`
- **Auth**: Không yêu cầu (`mfa_token` được gửi trong body)

---

## Input (Request Body)

| Field   | Required | Type   | Ghi chú                                           |
|---------|----------|--------|---------------------------------------------------|
| otp     | ✅       | string | OTP 6 chữ số từ authenticator app                |
| session | ✅       | string | Auth0 `mfa_token` nhận từ com-001 (MFA case)     |
| email   | ✅       | string | Email user (dùng để lấy profile)                 |

---

## Output (Response to Frontend)

| Field         | Required | Type      | Ghi chú                             |
|---------------|----------|-----------|-------------------------------------|
| processStatus | ✅       | number    | 1 = SUCCESS                         |
| message       | ✅       | string[]  |                                     |
| authenticated | ✅       | true      |                                     |
| session       | ✅       | UISession | Frontend-safe session               |
| redirectTo    | ✅       | string    | `/onboarding`, `/dashboard`, `/admin`|

---

## Backend API Gọi

| Method | URL                | Ghi chú                                      |
|--------|--------------------|----------------------------------------------|
| GET    | `/api/v1/users/me` | Lấy profile sau khi MFA verify thành công   |
