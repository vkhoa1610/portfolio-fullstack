# COM-005 — POST /auth/logout

## Process Flow

```
Frontend gửi POST (kèm HttpOnly cookies)
  → BFF đọc accessToken từ cookie
  → Gọi Cognito GlobalSignOut (invalidate tất cả tokens)
    (nếu thất bại vẫn tiếp tục — local logout luôn xảy ra)
  → clearAuthCookies (xóa toàn bộ HttpOnly cookies)
  → Trả { authenticated: false }
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-005`
- **Auth**: HttpOnly cookies

---

## Input

Không có request body.

---

## Output (Response to Frontend)

| Field         | Required | Type     | Ghi chú              |
|---------------|----------|----------|----------------------|
| processStatus | ✅       | number   | 1 = SUCCESS          |
| message       | ✅       | string[] |                      |
| authenticated | ✅       | false    | Luôn là `false`      |

---

## Backend API Gọi

Không gọi Java Backend. Chỉ gọi Cognito GlobalSignOut trực tiếp qua AWS SDK.
