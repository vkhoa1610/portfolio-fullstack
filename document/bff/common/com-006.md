# COM-006 — POST /onboarding/consent

## Process Flow

```
Frontend gửi { policyIds }
  → BFF validate: policyIds required, là array, không rỗng
  → BFF đọc idToken từ HttpOnly cookie (bắt buộc)
  → BFF lấy IP từ x-forwarded-for header (fallback: socket.remoteAddress)
  → BFF lấy User-Agent từ header
  → Forward đến Java Backend: POST /api/v1/onboarding/consent
      { policyIds, ipAddress, userAgent }
  → Trả success
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-006`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Request Body)

| Field     | Required | Type     | Ghi chú                              |
|-----------|----------|----------|--------------------------------------|
| policyIds | ✅       | number[] | ID các policy đã đồng ý (GDPR, ToS) |

---

## Output (Response to Frontend)

| Field         | Required | Type     | Ghi chú      |
|---------------|----------|----------|--------------|
| processStatus | ✅       | number   | 1 = SUCCESS  |
| message       | ✅       | string[] |              |

---

## Backend API Gọi

| Method | URL                          | Auth          |
|--------|------------------------------|---------------|
| POST   | `/api/v1/onboarding/consent` | Bearer idToken |
