# COM-003 — POST /auth/new-password

## Process Flow

```
Frontend gửi { username, newPassword, session } (session lấy từ com-001 response)
  → BFF gọi Cognito RespondToAuthChallenge (NEW_PASSWORD_REQUIRED)
  → Cognito trả AuthenticationResult
  → setAuthCookies (HttpOnly: accessToken, idToken, refreshToken)
  → fetchUserProfile (GET /api/v1/users/me)
  → buildUISession → trả LoginSuccessResponse
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/com-003`
- **Auth**: Không yêu cầu (session Cognito được gửi trong body)

---

## Input (Request Body)

| Field       | Required | Type   | Ghi chú                                               |
|-------------|----------|--------|-------------------------------------------------------|
| username    | ✅       | string | Email user                                            |
| newPassword | ✅       | string | Mật khẩu mới (thay thế temp password)                |
| session     | ✅       | string | Cognito session nhận từ com-001 (new password case)   |

---

## Output (Response to Frontend)

| Field         | Required | Type      | Ghi chú                             |
|---------------|----------|-----------|-------------------------------------|
| processStatus | ✅       | number    | 1 = SUCCESS                         |
| message       | ✅       | string[]  |                                     |
| authenticated | ✅       | true      |                                     |
| session       | ✅       | UISession | Frontend-safe session               |
| redirectTo    | ✅       | string    | `/onboarding` hoặc `/dashboard`     |

---

## Backend API Gọi

| Method | URL                | Ghi chú                                         |
|--------|--------------------|-------------------------------------------------|
| GET    | `/api/v1/users/me` | Lấy profile sau khi đổi mật khẩu thành công   |
