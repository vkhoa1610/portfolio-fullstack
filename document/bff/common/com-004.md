# COM-004 — GET /auth/session

## Process Flow

```
Frontend gửi GET (kèm HttpOnly cookies tự động)
  → BFF đọc accessToken + idToken từ cookies
  ├── Không có token → trả { authenticated: false }
  ├── Token hợp lệ → fetchUserProfile (GET /api/v1/users/me)
  │     → buildUISession → trả SessionResponse
  └── Token hết hạn → Cognito RefreshToken
        → setAuthCookies mới
        → fetchUserProfile → buildUISession → trả SessionResponse
```

> Dùng sau mỗi lần reload trang để re-hydrate Redux session.

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/com-004`
- **Auth**: HttpOnly cookies (tự động gửi qua `credentials: 'include'`)

---

## Input

Không có request body. Token được đọc từ HttpOnly cookies.

---

## Output (Response to Frontend)

| Field         | Required | Type      | Ghi chú                                          |
|---------------|----------|-----------|--------------------------------------------------|
| processStatus | ✅       | number    | 1 = SUCCESS                                      |
| message       | ✅       | string[]  |                                                  |
| authenticated | ✅       | boolean   | `false` nếu không có / không hợp lệ             |
| session       | ❌       | UISession | Chỉ có khi `authenticated: true`                |
