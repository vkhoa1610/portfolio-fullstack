# EMP-003 — POST /expenses

## Process Flow

```
Frontend gửi CreateExpenseRequest
  → BFF validate idToken từ cookie
  → BFF validate: type phải là RECEIPT | PER_DIEM | MILEAGE
  → Forward toàn bộ body đến Java Backend: POST /api/v1/expenses
  → Backend lưu expense với status = DRAFT
  → Trả Expense object
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/emp-003`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Request Body)

| Field          | Required | Type         | Ghi chú                                  |
|----------------|----------|--------------|------------------------------------------|
| type           | ✅       | string       | `RECEIPT` \| `PER_DIEM` \| `MILEAGE`   |
| title          | ❌       | string       | Tiêu đề expense                          |
| amount         | ❌       | number       | Tổng tiền                                |
| currency       | ❌       | string       | Mã tiền tệ (mặc định: `EUR`)            |
| vendorName     | ❌       | string       | *(RECEIPT)* Tên vendor                   |
| receiptDate    | ❌       | string       | *(RECEIPT)* Ngày receipt (ISO date)     |
| vatAmount      | ❌       | number       | *(RECEIPT)* Tiền VAT                     |
| receiptFileUrl | ❌       | string       | *(RECEIPT)* URL file ảnh receipt         |
| aiExtractedData| ❌       | string       | *(RECEIPT)* Data OCR từ AI (JSON string) |
| aiFlags        | ❌       | string       | *(RECEIPT)* Flags từ AI (JSON string)   |
| tripFrom       | ❌       | string       | *(PER_DIEM)* Điểm xuất phát             |
| tripTo         | ❌       | string       | *(PER_DIEM)* Điểm đến                   |
| countryCode    | ❌       | string       | *(PER_DIEM)* Mã quốc gia                |
| perDiemRate    | ❌       | number       | *(PER_DIEM)* Mức per diem/ngày          |
| perDiemDays    | ❌       | number       | *(PER_DIEM)* Số ngày                    |
| distanceKm     | ❌       | number       | *(MILEAGE)* Số km                       |
| ratePerKm      | ❌       | number       | *(MILEAGE)* Mức tiền/km                 |
