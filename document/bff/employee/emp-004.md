# EMP-004 — GET /expenses

## Process Flow

```
Frontend gửi GET
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: GET /api/v1/expenses
  → Backend trả danh sách expense của user hiện tại (theo idToken)
  → Trả Expense[]
```

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/emp-004`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input

Không có request body / query params.

---

## Output (Response to Frontend)

Trả về mảng `Expense[]`.

| Field          | Required | Type     | Ghi chú                                         |
|----------------|----------|----------|-------------------------------------------------|
| id             | ✅       | number   | ID expense                                      |
| userSub        | ✅       | string   | Cognito sub của user                            |
| type           | ✅       | string   | `RECEIPT` \| `PER_DIEM` \| `MILEAGE`          |
| status         | ✅       | string   | `DRAFT` \| `PENDING_REVIEW` \| `APPROVED` \| `REJECTED` |
| currency       | ✅       | string   | Mã tiền tệ                                      |
| title          | ❌       | string   |                                                 |
| amount         | ❌       | number   |                                                 |
| submittedAt    | ❌       | string   | ISO datetime                                    |
| rejectionReason| ❌       | string   | Có khi status = REJECTED                        |
| createdAt      | ❌       | string   | ISO datetime                                    |

---

## Backend API Gọi

| Method | URL                | Auth           |
|--------|--------------------|----------------|
| GET    | `/api/v1/expenses` | Bearer idToken |
