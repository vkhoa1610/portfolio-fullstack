# EMP-006 — POST /expenses/:id/submit

## Process Flow

```
Frontend gửi POST /api/emp-006/:id
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: POST /api/v1/expenses/:id/submit (body rỗng)
  → Backend đổi status: DRAFT → PENDING_REVIEW
  → Trả { processStatus, message }
```

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/emp-006/:id`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Path Params)

| Field | Required | Type   | Ghi chú              |
|-------|----------|--------|----------------------|
| id    | ✅       | number | ID expense cần submit |

Không có request body.

---

## Output (Response to Frontend)

| Field         | Required | Type     | Ghi chú      |
|---------------|----------|----------|--------------|
| processStatus | ✅       | number   | 1 = SUCCESS  |
| message       | ✅       | string[] |              |

---

## Backend API Gọi

| Method | URL                            | Auth           |
|--------|--------------------------------|----------------|
| POST   | `/api/v1/expenses/:id/submit`  | Bearer idToken |

Request body rỗng `{}`.
