# EMP-002 — POST /expenses/scan

## Process Flow

```
Frontend gửi { fileUrl } (fileUrl nhận được từ emp-001 sau khi upload)
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: POST /api/v1/expenses/scan { fileUrl }
  → Backend thực hiện Mock OCR (trả data đã mock sẵn: REWE GmbH 47.80€)
  → Trả ScanResponse cho frontend
```

> Frontend dùng kết quả để pre-fill form tạo expense.

---

## BFF Endpoint

- **Method**: POST
- **Path**: `/api/emp-002`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Request Body)

| Field   | Required | Type   | Ghi chú                                      |
|---------|----------|--------|----------------------------------------------|
| fileUrl | ✅       | string | Public URL của file đã upload lên MinIO      |

---

## Output (Response to Frontend)

| Field     | Required | Type     | Ghi chú                             |
|-----------|----------|----------|-------------------------------------|
| vendor    | ✅       | string   | Tên vendor (ví dụ: REWE GmbH)       |
| date      | ✅       | string   | Ngày trên receipt (ISO date)        |
| amount    | ✅       | number   | Tổng tiền                           |
| vatAmount | ✅       | number   | Tiền VAT                            |
| vatRate   | ✅       | string   | Tỷ lệ VAT (ví dụ: "19%")           |
| flags     | ✅       | string[] | Cờ cảnh báo từ AI (có thể rỗng)    |

---
