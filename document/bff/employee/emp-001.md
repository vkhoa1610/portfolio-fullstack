# EMP-001 — GET /expenses/upload-url

## Process Flow

```
Frontend gửi GET ?filename=xxx
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: GET /api/v1/expenses/upload-url?filename=xxx
  → Backend tạo presigned PUT URL từ MinIO (TTL 15 phút)
  → Trả { uploadUrl, fileUrl }
```

> Frontend dùng `uploadUrl` để PUT file thẳng lên MinIO (không qua BFF).
> Sau khi upload xong, `fileUrl` được dùng để gọi emp-002 (scan).

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/emp-001`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Query Params)

| Field    | Required | Type   | Ghi chú                           |
|----------|----------|--------|-----------------------------------|
| filename | ✅       | string | Tên file upload (có extension)    |

---

## Output (Response to Frontend)

| Field     | Required | Type   | Ghi chú                                       |
|-----------|----------|--------|-----------------------------------------------|
| uploadUrl | ✅       | string | Presigned PUT URL — dùng để upload trực tiếp  |
| fileUrl   | ✅       | string | Public URL của file sau khi upload             |

---

## Backend API Gọi

| Method | URL                                       | Auth           |
|--------|-------------------------------------------|----------------|
| GET    | `/api/v1/expenses/upload-url?filename=xxx` | Bearer idToken |
