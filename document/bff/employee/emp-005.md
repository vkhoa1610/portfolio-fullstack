# EMP-005 — GET /expenses/:id

## Process Flow

```
Frontend gửi GET /api/emp-005/:id
  → BFF validate idToken từ cookie
  → Forward đến Java Backend: GET /api/v1/expenses/:id
  → Backend trả chi tiết expense
  → Trả Expense object
```

> Endpoint này được dùng lại bởi mgr-004 cho Manager xem chi tiết.

---

## BFF Endpoint

- **Method**: GET
- **Path**: `/api/emp-005/:id`
- **Auth**: HttpOnly cookies (idToken required)

---

## Input (Path Params)

| Field | Required | Type   | Ghi chú    |
|-------|----------|--------|------------|
| id    | ✅       | number | ID expense |
